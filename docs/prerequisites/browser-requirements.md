# ブラウザ要件

Ivanti Neurons Platform の管理コンソールにアクセスする際に、サポート対象となっているブラウザの一覧です。POC で管理コンソールを操作する端末が、対応ブラウザを利用していることを確認してください。

!!! info "参照元"
    - [サポートされているブラウザ](https://help.ivanti.com/ht/help/ja_JP/CLOUD/vNow/supported-browsers.htm)

---

## サポート対象ブラウザ

- Chrome *(シークレット モードはサポート対象外)*
- Safari
- Firefox *(モバイルでは表示のみで、操作はサポート対象外)*
- Edge
- Edge Chromium
