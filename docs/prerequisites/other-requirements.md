# その他

上記の前提条件を満たしていても、エージェントの登録に失敗する場合や、特定の環境・エンドポイントでのみ不規則に問題が発生する場合があります。そうした事象が発生した際に、必要に応じて確認する項目です。

---

## SSL インスペクション/オフロードの確認

ファイアウォールやプロキシで SSL インスペクション(TLS 通信を一度復号して検査する機能)が有効になっていると、証明書の不一致によりエージェントの登録・通信が失敗することがあります。SSL オフロード機器(ロード バランサなど)を経由する構成でも同様の問題が起こり得ます。

- [ネットワーク要件](network-requirements.md)に記載の URL(特に `*.ivanticloud.com` 系のドメイン)を、SSL インスペクション/オフロードの対象から除外できないか確認してください。
- 除外が難しい場合は、エージェントの登録・通信に必要な証明書失効リスト(CRL)用 URL への到達性が損なわれていないか確認してください。

## ウイルス対策サービスの除外設定

ウイルス対策/EDR 製品のリアルタイム スキャン対象に Neurons Agent のインストール フォルダやプロセスが含まれていると、動作の遅延や誤検知の原因になることがあります。
