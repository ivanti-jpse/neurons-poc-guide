# POC 検証項目一覧

## Edge Intelligence

対応ガイド: [Edge Intelligence](../neurons/edge-intelligence.md)

| # | カテゴリ | 検証項目 | 期待結果 |
| --- | --- | --- | --- |
| 1 | マップ確認 | ランディング ページのマップでエージェントの所在地が表示されることを確認できるか | デバイスの所在地に応じたマーカーがマップ上に表示される |
| 2 | CPU/メモリ確認 | 対象デバイスのデバイス ダッシュボードでメモリ使用率のスナップショットを確認できるか | メモリ使用率(%)と使用中プロセスが表示される |
| 3 | CPU使用率履歴 | CPU ウィジェットから「CPU 使用率の履歴」ウィジェットを開けるか | 「`<デバイス名>` 上の CPU 使用率の履歴」ウィジェットが開き、折れ線グラフが表示される |
| 4 | CPU使用率履歴 | リスト ビューに切り替えた状態で、履歴データを CSV にエクスポートできるか(チャート ビューにはエクスポート アイコンは表示されない) | クエリ結果が CSV ファイルとしてローカルにダウンロードされる |
| 5 | コンソール確認 | Edge Intelligence のクエリ ウィジェットをお気に入りに登録し、再利用できるか | ハート アイコンでお気に入りに追加され、一覧の「お気に入り」セクションに表示される |
