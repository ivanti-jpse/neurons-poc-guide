# POC 検証項目一覧

POC で実施する検証項目の一覧です。ガイドの各ページに対応する確認項目を、参照用にまとめています。

## ボット

対応ガイド: [ボット](../neurons/bots.md)

| # | カテゴリ | 検証項目 | 期待結果 |
| --- | --- | --- | --- |
| 1 | 公開 | ボットを保存して公開できるか | 新規バージョンが作成され、ボット一覧のステータスが [アクティブ] になる |
| 2 | 実行 | 対象デバイスの詳細ページでアクション パネルを開けるか | [カスタム アクション] セクションに作成したボットが一覧表示される |
| 3 | 実行 | カスタム アクション メニューから [ブラウザキャッシュのクリア] を実行できるか | 「ボットは現在実行中です」というメッセージが表示される |
| 4 | 結果確認 | 通知(ベル アイコン)にアクション完了の通知が表示されるか | [Neurons Bots アクション完了] 通知に「正常に実行されました」と表示される |
| 5 | 結果確認 | [ボット] > 対象ボット > [トリガ履歴] で実行結果を確認できるか | 試行済み/実行済みの件数が加算されている |
