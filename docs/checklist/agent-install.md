# POC 検証項目一覧

POC で実施する検証項目の一覧です。ガイドの各ページに対応する確認項目を、参照用にまとめています。

## Neurons Agent のインストール

対応ガイド: [エージェントのインストール](../neurons/agent-install.md)

| # | カテゴリ | 検証項目 | 期待結果 |
| --- | --- | --- | --- |
| 1 | 事前準備 | 対象デバイスの OS がサポート対象であることを確認できるか | 互換性マトリックスに記載の OS/バージョンと一致 |
| 2 | 事前準備 | エージェント ポリシーを作成できるか | [エージェント ポリシー] の一覧に表示される |
| 3 | 事前準備 | 登録キーを作成し、ポリシーに関連付けできるか | [登録キー] の一覧に表示される |
| 4 | インストール | インストーラーのダウンロードと配布ができるか | 対象デバイス上にインストーラーが配置されている |
| 5 | インストール | エージェントのインストールが正常に完了するか | エラーなくインストールが終了する |
| 6 | インストール (macOS のみ) | 権限ダイアログをすべて許可できるか(または MDM プロファイルで事前設定できるか) | 権限の許可漏れがない |
| 7 | 登録確認 | エンドポイント上でエージェントのプロセスが起動しているか | Windows: `STAgent` / `STDownloader` / `STDispatch` が動作 |
| 8 | 登録確認 | エージェント エンジンがダウンロードされているか | `C:\ProgramData\Ivanti\Ivanti Cloud Agent` 配下にエンジンが存在 |
| 9 | コンソール確認 | [エージェント管理] にデバイスがアクティブで表示されるか | ステータスがアクティブ、正常性が良い(緑) |
| 10 | コンソール確認 | [デバイス] ワークスペースにデバイスが表示されるか | デバイスが一覧に表示される |
| 11 | コンソール確認 | インベントリ情報(OS・ハードウェア情報など)が取得できているか | デバイス詳細に基本情報が反映されている(数分のタイムラグあり) |
| 12 | ポリシー確認 | 割り当てたポリシーの機能がデバイスに反映されているか | ポリシーで有効化した機能のエンジンが動作している |
