# POC 検証項目一覧

POC で実施する検証項目の一覧です。ガイドの各ページに対応する確認項目を、参照用にまとめています。

## Neurons Agent のインストール

対応ガイド: [エージェントのインストール](../neurons/agent-install.md)

| # | カテゴリ | 検証項目 | 期待結果 |
| --- | --- | --- | --- |
| 1 | インストール | エージェントのインストールが正常に完了するか | エラーなくインストールが終了する |
| 2 | 登録確認 | エージェント エンジンがダウンロードされているか | `C:\ProgramData\Ivanti\Ivanti Cloud Agent` 配下にエンジンが存在 |
| 3 | コンソール確認 | [エージェント管理] にデバイスがアクティブで表示されるか | ステータスがアクティブ、正常性が良い(緑) |
| 4 | コンソール確認 | [デバイス] ワークスペースにデバイスが表示されるか | デバイスが一覧に表示される |
| 5 | コンソール確認 | インベントリ情報(OS・ハードウェア情報など)が取得できているか | デバイス詳細に基本情報が反映されている(数分のタイムラグあり) |
