# Neurons Agent のインストール

Ivanti Neurons Platform を利用するには、管理対象の各エンドポイントに **Neurons Agent** をインストールする必要があります。
本ページでは、エージェント展開の全体ワークフローと、各 OS へのインストール手順を解説します。

!!! info "参照元"
    本手順は Ivanti 公式ドキュメント(日本語版)に基づいています。最新情報は以下を参照してください。

    - [エージェント配布](https://help.ivanti.com/ht/help/ja_JP/CLOUD/vNow/agent-deployment.htm)
    - [エージェント管理の基本操作](https://help.ivanti.com/ht/help/ja_JP/CLOUD/vNow/agents-getting-started.htm)

## 展開ワークフローの全体像

エージェント展開は、次の 3 ステップで構成されます。

``` mermaid
graph LR
  A[1. ポリシー作成] --> B[2. 登録キー作成] --> C[3. エージェント配布]
```

### 1. エージェント ポリシーの作成

**[エージェント] > [エージェント ポリシー]** で、エンドポイントに適用するポリシーを定義します。主な設定項目:

- 機能 (Capabilities)
- 再起動エクスペリエンス
- メンテナンス ウィンドウ
- ダウンロード制御・帯域幅使用率などのエージェント設定

### 2. 登録キーの作成

**[エージェント] > [登録キー]** で、エージェントをテナントに登録するためのキーを作成し、手順 1 のポリシーに関連付けます。

- **上限を使用** — アクティベーション回数(エージェント エンドポイントの数)と有効期限を制限する場合に選択
- **最大数を使用** — 最大アクティベーション数・無期限で運用する場合に選択

### 3. 展開方式の選択

**[エージェント] > [エージェント配布]** で、環境に応じた展開方式を選択します。

| 方式 | 概要 | 向いているケース |
| --- | --- | --- |
| **自動ポリシー割り当て (APA)** | 設定可能なルールに基づき、デバイスへのポリシー割り当てを自動管理 | 大規模環境・ポリシー管理を中央集権化したい場合 |
| **Neurons プッシュ インストール** | コンソールからターゲットデバイスへエージェントをプッシュ展開 | 社内ネットワーク上のデバイスに一括展開したい場合 |
| **手動インストール** | インストーラーをダウンロードし、各デバイスで実行(インタラクティブ / サイレントの 2 モード) | POC・検証環境、少数台への導入 |

!!! tip "POC ではまず手動インストール"
    POC では動作を 1 台ずつ確認しながら進められる**手動インストール**から始めることを推奨します。
    本番展開のフェーズで自動ポリシー割り当て / プッシュ インストールに切り替える流れが検証しやすい構成です。

## 手動インストール手順

**[エージェント] > [エージェント配布]** の **[手動インストール]** タブを開くと、手動インストール用のフォームが表示されます。
以降は共通で次の 2 点を選択します。

1. **エージェント ポリシーの選択** — ドロップダウンから割り当てるポリシーを選択(または **[自動ポリシー割り当てを使用]** を選択)
2. **登録キーの選択** — 登録に使用するキーを選択。新規作成する場合は **[キーの新規作成]** を選択([登録キーの作成] パネルが表示されます)

その後、**[ホスト エンドポイントのオペレーティング システムを選択]** で対象 OS のタイルを選び、以下の手順でインストールします。

=== "Windows"

    1. **Windows** タイルを選択します
    2. **インストール モード**で **インタラクティブ** を選択します(既定値)
    3. **[ダウンロード]** をクリックし、実行ファイルと構成ファイルの 2 点をまとめて取得します
    4. 対象エンドポイントに、この 2 ファイルを同じディレクトリに配布します
    5. 実行ファイルをダブルクリックして、エージェントをインストールします

    !!! note
        インストール完了後の登録(レジストレーション)状況は、後述の「インストール後の確認」で検証します。

    !!! tip "サイレント インストールとの違い"
        **インストール モード**で **サイレント** を選択した場合は、実行ファイルの配布に加えて、
        画面に表示される **Command** をコピーし、インストール パラメータとともにコマンドラインで実行する方式になります。
        無人展開(スクリプトや、SCCM / Intune などの既存の Windows 管理製品経由の一斉配布など)を行う場合はサイレント モードを検討してください。

=== "macOS"

    1. **MacOS** タイルを選択します
    2. **インストール モード**で **インタラクティブ** を選択します(既定は **サイレント** のため、切り替えが必要です)
    3. **[ダウンロード]** をクリックしてインストーラーを取得し、対象エンドポイントで実行します
    4. インストール中に、位置情報サービス(ロケーションセンサー用)を含む
       **複数の権限許可・通知ダイアログ**が表示されます。エージェントが正しく機能するには、
       これらをすべて許可・設定する必要があります

    !!! tip "MDM プロファイルによる事前許可"
        これらの権限の大半は、MDM 配布プロファイルで事前に許可設定できます。
        Ivanti Community の KB 記事「**MDM Profiles for Ivanti Neurons**」で提供されているプロファイルを利用してください。
        (Neurons for MDM / EPMM 管理下のデバイスであれば、このプロファイル配布と組み合わせるのが実運用的です)

=== "Linux"

    1. **Linux** タイルを選択し、**バージョン** ドロップダウンから対象ディストリビューションを選択します
    2. **[ダウンロード]** をクリックしてインストールファイル(`.sh`)を取得します
    3. 対象エンドポイントで root シェルを開き、ダウンロードしたファイルの場所へ移動します
    4. インストールファイルに実行権限を付与し、実行します

    !!! note "作成されるユーザー"
        インストールプロセスで作成されるユーザーは `ivanticloudagent` の 1 つのみです。
        このユーザーはエージェントのアンインストール時に削除されます。

## インストール後の確認

エージェントの登録が正常に完了したかを、以下の観点で確認します。

### エンドポイント側(Windows)

1. `C:\ProgramData\Ivanti\Ivanti Cloud Agent` フォルダを開き、エンジン群が正しくダウンロードされているか確認します
2. タスクマネージャーで以下のプロセスが動作しているか確認します
    - `STAgent`
    - `STDownloader`
    - `STDispatch`
3. コントロールパネルで、ポリシーに設定したエージェントエンジンが列挙されているか確認します

### Neurons コンソール側

1. **[エージェント] > [エージェント管理]** を開き、インストールしたデバイスがステータス **アクティブ** で表示されることを確認します
2. **[デバイス]** ワークスペースにデバイスが表示されることを確認します

!!! note "インベントリ反映のタイムラグ"
    インベントリ情報がコンソールに反映されるまで数分かかる場合があります。
    その間もデバイスの基本情報は確認できます。

## トラブルシューティングの入口

| 症状 | 最初に確認すること |
| --- | --- |
| コンソールにデバイスが表示されない | 登録キーの有効期限・アクティベーション上限。エンドポイントからテナントへの通信(プロキシ/FW) |
| エージェントが登録できない | CRL 用 URL・基幹通信 URL(`tkuprd-sfc.ivanticloud.com`)への疎通、プロキシのインライン SSL 検査設定 |
| デバイスがオフライン表示のまま | エンドポイントからテナントへの MQTT 通信(プロキシ/FW) |
| エージェントは入ったが機能が動かない | エージェント ポリシーの機能 (Capabilities) 設定の有効化漏れ |
| macOS で一部センサーが動かない | 権限ダイアログの許可漏れ。MDM プロファイルでの事前設定を検討 |
