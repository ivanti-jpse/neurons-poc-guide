# Neurons Agent のアンインストール

不要になったエンドポイントや、再検証のためにクリーンな状態へ戻したいエンドポイントから、**Neurons Agent** を削除する手順を解説します。
コンソールからのアンインストールと、コンソールにアクセスできない場合の手動アンインストール(OS 別コマンド)の両方を扱います。

!!! info "参照元"
    本手順は Ivanti 公式ドキュメント(日本語版)に基づいています。最新情報は以下を参照してください。

    - [エージェント管理](https://help.ivanti.com/ht/help/ja_JP/CLOUD/vNow/agent-management.htm)

---

## 全体ワークフロー

コンソールからのアンインストールは、次の 3 ステップで構成されます。

``` mermaid
graph LR
  A["1. 対象エージェント<br>エンドポイントの選択"] --> B["2. アクション メニュー<br>から選択"] --> C["3. 確認ダイアログ<br>での実行"]
```

!!! danger "アンインストールは取り消せません"
    エージェントのアンインストールを実行すると元に戻せません。再度そのエンドポイントを管理対象にするには、
    登録キーを使った再インストールが必要です。POC 環境で対象デバイスを継続利用する場合は、
    実行前に対象デバイス名を必ず再確認してください。

### 1. 対象エージェント エンドポイントの選択

**[エージェント] > [エージェント管理]** を開き、検索ボックスにデバイス名を入力して対象を絞り込み、
一覧の該当行の**チェック ボックス**をオンにします。

### 2. アクション メニューからの選択

画面左上の **[アクション]** をクリックし、表示されるメニューから **[エージェントのアンインストール]** を選択します。

実機のコンソールで確認したところ、**[アクション]** メニューには次の 4 項目が表示されます(いずれも日本語版ヘルプの表記と一致)。

- [ポリシーの再割り当て]
- [エージェントの再配布]
- **[エージェントのアンインストール]**
- [エージェント エンドポイントの削除]

### 3. 確認ダイアログでの実行

**[エージェントのアンインストール]** を選択すると、**[エージェントのアンインストール]** ダイアログが表示されます。
内容(対象デバイス名)を確認し、問題なければ **[アンインストール]** をクリックして実行します。

エージェントがアンインストールされると、**[エージェント管理]** ページを更新した時点で、そのエージェント エンドポイントは一覧から表示されなくなります。

!!! note "検証目的で手順のみ確認する場合"
    対象デバイスを継続して使う POC 環境では、**[アンインストール]** ボタンをクリックする直前まで手順を確認し、
    実際の実行はデバイスが本当に不要になったタイミングまで控えることを推奨します。

## 手動アンインストール手順(OS コマンド)

コンソールからのアンインストールに失敗した場合や、エンドポイント側で直接操作したい場合は、以下のコマンドを使用します。

=== "Windows"

    1. 管理者権限でコマンド プロンプトまたは PowerShell を開きます
    2. 以下のコマンドを実行します

        ```powershell
        C:\Program Files\Ivanti\Ivanti Cloud Agent\STAgentManagement.exe -uninstall
        ```

    3. アンインストール ログは以下に出力されます

        ```
        C:\ProgramData\Ivanti\Ivanti Cloud Agent\Logs\AGENT_uninstall.log
        ```

    !!! tip "パラメータの確認"
        利用可能なパラメータの一覧は、次のコマンドで確認できます。

        ```powershell
        C:\Program Files\Ivanti\Ivanti Cloud Agent\STAgentManagement.exe /?
        ```

=== "macOS"

    1. ターミナル、またはデバイス管理アプリケーションから以下のコマンドを実行します

        ```bash
        /usr/local/com.ivanti.cloud.agent/IvantiAgent/bin/stagentctl uninstall
        ```

    2. システム設定の **[ユーザとグループ]** で `_ivantiNeuronsMacPatchAgent` アカウントを削除します。
       またはコマンドで削除します

        ```bash
        sudo sysadminctl -deleteUser _ivantiNeuronsMacPatchAgent
        ```

    !!! note
        macOS の場合、アンインストール ログは残りません。

=== "Linux"

    1. root シェルで以下のコマンドを実行します

        ```bash
        yum remove ivanticloudagent
        ```

    2. アンインストール ログは以下に出力されます

        ```
        /opt/ivanti/cloudagent
        ```

!!! warning "手動アンインストール後は必ずコンソール側の後処理が必要"
    エンドポイント側でエージェントを手動アンインストールしても、コンソールの **[エージェント管理]** 一覧からは自動的に消えません。
    次の「エージェント エンドポイントの削除」を実施してください。

---

## エージェント エンドポイントの削除(手動アンインストール後)

手動でアンインストールした場合や、ステータスが進行しないままになっている場合は、一覧からエンドポイント情報自体を削除します。

1. 削除対象のエージェント エンドポインドの横のチェック ボックスをオンにします
2. **[アクション] > [エージェント エンドポイントの削除]** を選択します。**[エージェント エンドポイントの削除]** 確認ダイアログが表示されます
3. **[削除]** をクリックします

実行後、そのエージェント エンドポイントは **[エージェント管理]** ページの一覧に表示されなくなります。

## 手順後の確認

### Neurons コンソール側

1. **[エージェント] > [エージェント管理]** を開き、対象デバイスが一覧から消えていることを確認します
2. **[デバイス]** ワークスペースの表示は、**[Setup] > [設定]** の **[データ保持管理]** 設定に依存します。
    **[レコードの自動削除]** が有効な場合、検出されなくなったデバイス レコードは、設定した日数(既定 30日など)の経過後に自動的に削除され、
    **[デバイス]** ワークスペースからも表示されなくなります。この設定が無効な場合は、レコードは自動削除されず手動での確認・削除が必要です。

### エンドポイント側

1. Windows の場合、コントロール パネルの **[アプリケーションの追加と削除]** からエージェント プログラムが削除されていることを確認します
2. アンインストール ログが出力されている場合は、エラーが記録されていないか確認します

## トラブルシューティングの入口

| 症状 | 最初に確認すること |
| --- | --- |
| コンソールから [エージェントのアンインストール] を実行しても一覧から消えない | デバイスがオフライン/通信不可の可能性。ステータス列の情報を確認し、手動アンインストール + [エージェント エンドポイントの削除] に切り替える |
| 手動アンインストール後もコンソールに残り続ける | 「エージェント エンドポイントの削除」アクションが未実施。手順を参照して実施する |
| macOS でアンインストール後も一部プロセス・アカウントが残る | `_ivantiNeuronsMacPatchAgent` アカウントの削除漏れ。手動削除コマンドを再実行する |
