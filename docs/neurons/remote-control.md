# Neurons プラットフォームでのリモート コントロール

Ivanti Neurons プラットフォームのリモート コントロールを使用すると、リモート コントロールの権限を持つ IT アナリストが、ブラウザだけでエンドポイントに安全に接続し、トラブルシューティングやユーザ支援を行えます。追加のネットワーク インフラストラクチャは不要です。

## 全体ワークフロー

本ページでは、エンドポイント側の許可操作を必要としない**無人リモート コントロール**(エンドユーザ権限を要求しない構成)の利用手順を解説します。リモート コントロールの利用は、次の 4 ステップで構成されます。

``` mermaid
graph LR
  A["1. 無人リモート<br/>接続を設定"] --> B["2. ポリシーで<br/>機能を有効化"] --> C["3. エージェントを<br/>配布"] --> D["4. セッションを<br/>開始"]
```

### 1. 無人リモート コントロールの設定

**[Setup] > [リモート コントロール設定]** で対象設定(既定では **(SYSTEM) Default**)を開き、**[権限]** の **[エンドユーザ権限を要求]** をオフにします。オフにすると、エンドポイント側の許可ダイアログを待たずにセッションへ接続できます。

**[リモート デバイス制御]** では、必要に応じて次の機能も有効化しておきます。

- **[リモート コントロール アクションを有効にする]**
- **[ファイル転送を許可]**
- **[リモート実行を許可]**

!!! note "エンドユーザ権限を要求時のタイムアウト"
    **[エンドユーザ権限を要求]** をオンにする場合は、**[権限要求タイムアウト (秒)]** で許可ダイアログの待機時間(既定 60秒)を設定します。無人リモート コントロールではこの項目は使用されません。

### 2. ポリシーでのリモート コントロール機能の有効化

**[エージェント] > [エージェント ポリシー]** で対象ポリシーを開き、**[機能]** タブの **[リモート コントロール]** を有効化します。

> IT アナリストがエンドポイントを安全にリモート コントロールできるようにして、ユーザが抱える問題のトラブルシューティングを支援する機能です。

### 3. リモート コントロール対応エージェントの配布

**[エージェント] > [エージェント配布]** の **[手動インストール]** タブで、手順 2 で機能を有効化したポリシーを選択してエージェントを配布します。詳細な OS 別インストール手順は [エージェントのインストール](agent-install.md) を参照してください。

Ivanti Neurons Agent のブートストラップがインストールされた後、バックグラウンドでエージェント コンポーネントがダウンロードされるまで数分かかる場合があります。これが完了すると、そのエンドポイントに対するアクションとしてリモート コントロールを使用できるようになります。

### 4. リモート コントロール セッションの開始

デバイス詳細画面からセッションを開始します。手順は次章で解説します。

---

## リモート コントロール セッションの開始

1. **[デバイス]** ビューで、リモート コントロールするデバイスを見つけてクリックします。
2. デバイス詳細画面右側の **[アクション]** パネルで **[リモート コントロール]** をクリックします。

新しいタブにリモート コントロール ビューア ページ(RCViewer)がロードされます。エンドポイント側でのエージェント コンポーネントの動的ロード速度によっては、接続完了まで最大30秒ほどかかる場合があります。新しいタブが表示されない場合は、ブラウザのポップアップ ブロックを確認してください。

**[エンドユーザ権限を要求]** をオフにした無人リモート コントロールでは、エンドポイント側での許可待ちは発生せず、そのままセッションに接続されます。誰もログインしていない場合でも、アナリスト側の操作だけでセッションを開始できます。

リモート コントロールでは、ビデオ・キーボード・マウスを操作できます(オーディオは非対応)。セッション中は、エンドポイント画面の四辺に緑色の境界線と、右下にリモート コントロール通知が表示されます。

---

## チャット

セッション中にチャット ツールバー ボタンから、ターゲットとのテキスト チャットを開始できます。双方がタイムスタンプ付きメッセージを送信でき、チャット ウィンドウ下部のクリップボード アイコンで記録をコピーできます。セッション終了時にも、チャット内容をクリップボードに保存するかどうかのプロンプトが表示されます。

## ファイルの転送

ファイル転送ボタンから、ターゲットとの間でファイルの送受信ができます。

**ファイルをターゲットに転送するには**

1. ファイル転送ボタンをクリックします。
2. ドライブ文字をダブルクリックしてターゲットのファイル システムを参照します。
3. アップロード先フォルダに移動します。
4. **[アップロード]** をクリックし、ローカルのファイルを選択します。
5. **[開く]** をクリックすると転送されます。

**ファイルをターゲットから転送するには**

1. ファイル転送ボタンをクリックします。
2. ドライブ文字をダブルクリックしてターゲットのファイル システムを参照します。
3. ダウンロードするファイルに移動します。
4. **[ダウンロード]** をクリックし、保存先フォルダを選択します。
5. **[保存]** をクリックするとダウンロードされます。

フォルダをダウンロードする場合は、RCViewer が事前に zip 化してから転送します。

## リモートでファイルを実行する

リモート実行ボタンから、ターゲット上でコマンドやアプリケーションを実行できます。コマンド プロンプト/PowerShell のコマンドは出力がキャプチャされ、後から確認できます(Windows アプリケーションの起動では出力はキャプチャされません)。実行ユーザは、ローカル システム・ローカル システムと GUI・ログイン ユーザから選択できます。実行ステータス履歴はセッション終了時に消去されます。

## 手順後の確認

### エンドポイント側

1. セッション中、画面四辺に緑色の境界線が表示されていることを確認する
2. 画面右下にリモート コントロール通知が表示されていることを確認する

### Neurons コンソール側

1. デバイス詳細画面の **[アクション]** パネルに **[リモート コントロール]** が表示されることを確認する
2. **[レポート]** で「デバイス別リモート コントロール」「オペレータ別リモート コントロール」テンプレートからレポートを作成し、セッション履歴・成功率を確認する

!!! note "レポートの制限事項"
    リモート コントロール レポートで参照できるのは過去3か月分のデータのみです。また、セッション開始イベントのみを追跡するため、接続結果まですべて反映されるとは限りません。

## トラブルシューティングの入口

| 症状 | 最初に確認すること |
| --- | --- |
| [アクション] パネルに [リモート コントロール] が表示されない | エージェントのインストール状況、割り当てポリシーの [リモート コントロール] 機能が有効か |
| 新規タブが開かない/接続が始まらない | ブラウザのポップアップ ブロック設定、対応ブラウザ(Chrome/Firefox/Edge)を使用しているか |
| エンドポイント側に許可ダイアログが表示され、無人接続にならない | [リモート コントロール設定] の [エンドユーザ権限を要求] がオフになっているか |
| リモート コントロールが接続できない | `tkuprd-rc.ivanticloud.com` とポート範囲 44345–45347 (TCP) の許可設定([ネットワーク要件](../prerequisites/network-requirements.md)を参照) |
