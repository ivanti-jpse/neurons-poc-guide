# ボット

ボットのテンプレートを使って、エンドポイントに対して手動実行できる「カスタム アクション」を作成し、
[デバイス] のアクション メニューから実行・結果確認するまでの一連の流れを解説します。

## 全体ワークフローの全体像

カスタム アクション ボットの作成から実行確認までは、次の 4 ステップで構成されます。

``` mermaid

  A["1. テンプレートから<br/>ボット作成"] --> B["2. トリガ設定でカスタム<br/>アクションを有効化"] --> C["3. デバイス ビューから<br/>実行"] --> D["4. 結果を<br/>確認"]
```

### 1. テンプレートからボットを作成

### 2. トリガ設定でカスタム アクションを有効化・表示名を設定

### 3. [デバイス] のカスタム アクション メニューから実行

### 4. 通知・トリガ履歴で結果を確認

## 手順

### 1. テンプレートからボットを作成する

1. メイン メニューの **[ボット]** を開きます。**[ボット]** ページが表示されます。
2. **[ボットの作成]** を選択します。**[ボットの作成]** ページが表示されます。
3. **[テンプレートから開始]** タブを選択します。
4. 一致するテキストに「キャッシュ」などのキーワードを入力するか、一覧をスクロールして
   **[インターネット ブラウザのキャッシュのクリア]** テンプレート(説明: 「ブラウザのキャッシュをクリアします」)を探します。
5. 必要に応じて **[詳細]** を選択すると、テンプレートの用途が確認できます。
    - 本テンプレートは、ユーザのインターネット ブラウザの Cookie とキャッシュをクリアします。
    - 対象は次の 3 パターンから選択できます:「Cookie とキャッシュをクリアする」(既定)/「キャッシュのみをクリアする」/「Cookie のみをクリアする」
6. **[作成]** を選択します。**[下書きを作成]** ダイアログが表示されます。
7. **[名前]** にボット名(例: `ブラウザキャッシュのクリア`)を入力し、**[下書きを作成]** を選択します。
   ボット エディタが表示され、ボットは非アクティブな下書きバージョンとして保存されます。

!!! tip "説明欄はテンプレートの既定値のままで OK"
    テンプレートから作成した場合、**[説明]** 欄にはテンプレートの用途(選択可能なオプションの一覧)が
    あらかじめ入力されています。POC ではそのまま利用して問題ありません。

### 2. トリガ設定でカスタム アクションを有効化する

1. ボット エディタの作業領域で、最初のステージ **[カスタム アクション]** をクリックします。
   右側に **[トリガ設定]** パネルが開きます。
2. **[トリガ タイプ]** が **[カスタム アクション]** になっていることを確認します。
3. **[トリガ ステータス]** のトグルを **[非アクティブ]** から **[アクティブ]** に切り替えます。
   追加の設定項目が表示されます。
4. **[デバイス ビューの公開済みオプション]** で、カスタム アクションを公開する範囲を選択します。
    - **単一のデバイス** — [デバイス] で選択した 1 台に対して実行できるようにする場合に有効化(既定で有効)
    - **複数のデバイス** — [デバイス] で複数選択したデバイスに対して一括実行できるようにする場合に有効化

    !!! note
        いずれか一方は必ず有効にする必要があります。両方とも無効のままだと、ボットは
        [デバイス] にカスタム アクションとして公開されません。

5. 必要に応じて **[デバイス ビューのユーザ アクセス]** の **[ユーザ アクセスを制限]** を選択し、
   カスタム アクションを実行できるユーザ/ロールを絞り込みます(既定は全ユーザに表示)。
6. **[カスタム アクションの名前と説明]** で、**[カスタム アクション表示名]** に
   `ブラウザキャッシュのクリア` と入力します。この表示名が [デバイス] > [アクション] の一覧に表示されます。
   任意で **[説明]** も入力します。
7. 画面右上の **[保存して公開]** を選択します。**[保存して公開]** ダイアログで名前・説明・
   新規バージョン情報(バージョン番号、トリガ タイプ、トリガ ステータス)を確認し、
   **[保存して公開]** を選択します。

これでボットの新規バージョンが作成・公開され、カスタム アクションとして [デバイス] に表示されるようになります。

## デバイス ビューでの実行

対象デバイスに対してカスタム アクションを実行し、結果を確認します。

1. メイン メニューの **[デバイス]** を開き、対象デバイスを検索してクリックします。
   デバイス詳細ページが表示されます。
2. 右側の **[アクション]** パネルを開きます(表示されていない場合は右上の **[アクション]** ボタンをクリック)。
3. **[カスタム アクション]** セクションまでスクロールし、手順で有効化した
   **[ブラウザキャッシュのクリア]** の実行ボタン(再生アイコン)をクリックします。
   ダイアログが表示されます。
4. **[ボット入力]** で、ブラウザ データの選択(既定: 「Cookie とキャッシュ」)などのオプションを確認します。
5. **[実行]** をクリックします。「ボットは現在実行中です。このダイアログは閉じてもかまいません。
   引き続き作業できます。アクションが完了すると、Ivanti Neurons トレイに通知が表示されます。」というメッセージが表示されます。
6. **[閉じる]**(または ✕)でダイアログを閉じ、他の作業を継続できます。

## 結果の確認(コンソール)

エージェント側の確認は行わず、管理コンソール上で成功したことのみを確認します。

1. 画面右上の通知(ベル)アイコンをクリックします。**[通知]** パネルが表示されます。
2. 一覧に **[Neurons Bots アクション完了]** の通知が表示され、
   本文に「アクション '[表示名]' が正常に実行されました」と表示されていれば成功です。
3. 通知の **[結果を表示]** リンクをクリックすると、実行したステージごとのメッセージ ログ
   (対応ブラウザの検出結果、Cookie とキャッシュの削除完了メッセージなど)を確認できます。

!!! tip "トリガ履歴からも確認できる"
    **[ボット]** ホームページの対象ボット名をクリックし、**[トリガ履歴]** タブを開くと、
    試行済み/失敗/実行済みの回数や、デバイスごとの実行結果を一覧で確認できます。

## トラブルシューティングの入口

| 症状 | 最初に確認すること |
| --- | --- |
| [デバイス] のアクション パネルにカスタム アクションが表示されない | トリガ設定の [デバイス ビューの公開済みオプション] で単一/複数のデバイスが有効になっているか。ユーザ アクセス制限の対象に自分が含まれているか |
| 実行してもボットが完了しない/失敗する | 対象デバイスがオンラインか。デバイス実行動作(オンラインのみ実行/キューに入れる)の設定 |
| 通知にアクションの結果が表示されない | ブラウザをリロードするか、[ボット] > 対象ボット名 > [トリガ履歴] で直接確認する |
