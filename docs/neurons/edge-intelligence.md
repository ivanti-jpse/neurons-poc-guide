# Edge Intelligence

Edge Intelligence は、Ivanti Neurons エージェントを通じてデバイスからリアルタイムに情報を取得し、インベントリ・正常性・セキュリティ構成などをその場で確認できる機能です。マップによるデバイスの所在確認や、CPU/メモリ使用率の履歴確認など、トラブルシューティングに必要な情報をブラウザだけで取得できます。

## 全体ワークフロー

``` mermaid
graph LR
  A[1. Edge Intelligence構成でCPU/メモリ監視を有効化] --> B[2. Edge Intelligenceにアクセス] --> C[3. マップでデバイスの位置を確認] --> D[4. デバイス ダッシュボードでCPU/メモリを確認] --> E[5. CPU使用率の履歴で時系列を延ばして推移を確認]
```

### 1. Edge Intelligence 構成での CPU/メモリ監視の有効化

CPU・メモリ使用率の推移(履歴)を確認するには、事前に Edge Intelligence 構成でこれらのメトリクスの監視を有効にしておく必要があります。既定では監視が有効になっていない場合があるため、初回は必ずこの設定を確認します。

1. 左側メニューの **[Setup] > [Edge Intelligence 設定]** を選択します。
2. **[構成の作成]** をクリックし、**[新しい Edge Intelligence 構成]** ページを開きます。
3. **[構成名]**(および任意で **[説明]**)を入力します。
4. **[監視]** タブに切り替え、**[CPU 使用率]** と **[メモリの使用状況]** のトグルを有効にします。必要に応じて **[場所]**・**[バッテリーの正常性]**・**[ディスク領域]**・**[電源状態]**・**[Ivanti Application Monitor]** も有効にできます。
5. 右上の **[保存]** をクリックします。
6. 作成した構成を、対象デバイスに割り当てているエージェント ポリシーの Edge Intelligence 機能に選択します(手順は [エージェント ポリシー](agent-install.md) の機能設定を参照)。

!!! note "設定が反映されるタイミング"
    構成の割り当てや編集後、変更がエンドポイントに反映されるまでには、エージェントのチェックイン間隔を待つ必要があります。反映前は CPU 使用率の履歴にデータが蓄積されません。

### 2. Edge Intelligence へのアクセス

左側メニューの **[Insights] > [Edge Intelligence]** を選択します。既定では、アクセスすると **[エージェントの概要]** が開き、環境内のエージェントの位置を示すマップがランディング ページとして表示されます。

画面右上には、選択したターゲットに対するオンライン エンドポイント数が「x / y オンライン」の形式で表示されます。マップを閉じて既定の定義済みクエリの一覧を表示するには、マップ右上の **X** をクリックします。次回以降マップをスキップしたい場合は、マップ右上の **[ランディング ページとして表示]** チェックボックスの選択を解除します。

### 3. マップ画面でのデバイスの位置確認

**[エージェントの概要]** のマップには、環境内のエージェントの所在地がプロットされます。

1. 画面右上のターゲット選択ドロップダウン(既定は **[すべてのデバイス]**)で、定義済みのターゲット グループ、ターゲット デバイス、ターゲット デバイス グループを選択すると、マップとオンライン数の表示が更新されます。
2. マップ右上の切り取りアイコンを使うと、マップ上で任意の地域を矩形選択し、以降のクエリのフィルタ(地域フィルタ)として利用できます。
3. デバイスの位置情報を表示したくない場合は、エージェント ポリシーに適用している Edge Intelligence の構成で位置センサーを無効化できます。

!!! note "位置情報の仕組み"
    Windows デバイスでは Windows の位置情報サービスが優先され、無効な場合は IP アドレスによるオンライン位置検索にフォールバックします。macOS では、macOS の位置情報サービスが有効かつ Neurons エージェントへのアクセスが許可されている場合にのみ、この機能が使用されます。

### 4. デバイス ダッシュボードでの CPU/メモリ確認

1. **[デバイス]** ビューで対象デバイス(例: `client-2nchvny3`)をクリックし、デバイス詳細を開きます。
2. **[パフォーマンス]** タブ、または Edge Intelligence 側の「デバイス ダッシュボード」ウィジェットで、CPU・メモリ使用率のスナップショットを確認します。ウィジェットのタイトルは「デバイス ダッシュボード の対象デバイス '`<デバイス名>`'」の形式で表示されます。
3. CPU・メモリはそれぞれドーナツ グラフで現在の使用率(%)が表示され、その下に最も消費しているプロセス(Most consuming process)が表示されます。
4. 画面右側には、Reliability Index、Uptime、Installed Applications、ディスク空き容量、Device Drivers など、デバイスの状態を示す情報がまとめて表示されます。

!!! note "リアルタイム問い合わせについて"
    Edge Intelligence はリアルタイムでデバイスに問い合わせる機能のため、クエリ実行時にデバイスがオンラインである必要があります(オフラインのデバイスは応答が返りません)。

!!! note "スナップショットの性質"
    [デバイス詳細] の [パフォーマンス] タブに表示される CPU・メモリ使用率は、直近のビュー更新時点のスナップショットです。時系列の推移を確認する場合は、次の手順の CPU 使用率の履歴を使用します。

### 5. CPU 使用率の履歴で時系列を延ばして確認する

1. CPU ウィジェットのタイトル横にある折れ線グラフ アイコンをクリックし、「`<デバイス名>` 上の CPU 使用率の履歴」ウィジェットを開きます。
2. ウィジェット上部に、現在表示されている期間が `From: '<開始日時>'; To: '<終了日時>'` の形式で表示されます。既定では直近7日間程度が表示されます。
3. グラフ下部の期間選択スライダーの左右のハンドルをドラッグすることで、表示期間を延ばしたり狭めたりできます。期間を延ばすと、より長期間の CPU 使用率の推移(通常時の水準や、スパイクが発生したタイミング)を確認できます。
4. ウィジェット右上には、チャート ビュー/リスト ビューの切り替え、更新、ターゲットとパラメータ設定、履歴(期間)設定、閉じるの各アイコンが表示されます。**CSV エクスポートはこのチャート ビューには表示されません。**
5. リスト ビューに切り替えると、検索ボックスに加えて、コピー・**エクスポート(CSV)**・列フィルタ・その他メニューのアイコンが表示されます。CSV エクスポートを行う場合は、先にリスト ビューへ切り替えてからエクスポート アイコンをクリックします。

## トラブルシューティングの入口

| 症状 | 最初に確認すること |
| --- | --- |
| マップにデバイスが表示されない/位置がずれている | エンドポイントの位置情報サービスが有効か、Edge Intelligence 構成で位置センサーが無効化されていないか |
| クエリの応答数が 0 のまま増えない | 対象デバイスがオンラインか、Edge Intelligence 対応エージェントがインストールされているか |
| CPU 使用率の履歴ウィジェットが開かない/データが表示されない | Edge Intelligence 構成の [監視] タブで [CPU 使用率]・[メモリの使用状況] が有効になっているか、その構成がエージェント ポリシーに割り当てられているか |
| 期間を延ばしても古いデータが表示されない | Edge Intelligence はリアルタイム収集のため、対象期間中に監視設定が有効かつデバイスがオンラインだったか(設定前・オフライン中のデータは収集されない) |
