    アプリの配布

    Ivanti Neurons for Healing の アプリの配布 機能を使うと、.exe / .msi 形式のデスクトップ アプリケーションを、Neurons Agent 経由でエンドポイントに配布できます。 本ページでは、Notepad++ の MSI インストーラーを例に、アプリの登録から配布、配布後の確認までの手順を解説します。

    参照元

    本手順は Ivanti 公式ドキュメント(日本語版)に基づいています。最新情報は以下を参照してください。

    • アプリの配布
    • アプリの配布カタログ
    • アプリの配布構成
    • アプリの配布の配布ステータス

    全体ワークフロー

    アプリの配布は、次の 3 ステップで構成されます。

    graph LR
  A[1. アプリ配布機能の有効化] --> B[2. アプリの登録] --> C[3. 配布とステータス確認]

    1. 管理対象デバイスへのアプリの配布の有効化

    対象デバイスにアプリの配布用のエージェント コンポーネントを有効化します。

    1. [エージェント] > [エージェント ポリシー] を選択します。
    2. [ポリシーの作成] を選択するか、既存のポリシーを選択して [編集] します。
    3. [機能] セクションで [アプリの配布] を選択します。
    4. [ポリシーの作成](または [保存])をクリックします。
    5. アプリの配布でターゲットとするデバイスが、最新のエージェント ポリシーを使用していることを確認します。

    2. アプリ カタログへのアプリの登録

    [アプリの配布] メニューには、以下の 4 つのサブメニューがあります。

    メニュー 用途
    アプリ カタログ アプリ/パッケージ/バンドルの作成・配布状況の一覧
    アプリの構成 「1回インストール」「常にインストールが必要」などの共通インストール オプションの定義
    設定 アプリの配布全体に関わる設定
    配布ステータス 配布の進行状況・結果の確認

    3. 配布とステータス確認

    アプリを対象デバイスに紐づけ、配布ステータスで結果を確認します(詳細は後述)。

    手順: Notepad++ (MSI) の登録

    1. 新規アプリの作成

    1. [アプリの配布] > [アプリ カタログ] を選択します。

    2. [追加] をクリックし、表示された選択肢から [Windows] を選択します(手動ワークフロー)。

      追加の選択肢

      [追加] のドロップダウンには、他に [Windows パッケージ マネージャ (winget)]、[EPM パッケージをインポート]、[バンドル]、[OS 配布 (MS Windows のみ)] があります。 winget カタログにあるアプリを素早く登録したい場合は winget ワークフロー、Endpoint Manager のパッケージを移行する場合は EPM インポートを使用します。今回は MSI インストーラーを手動で組み立てるため [Windows] を選択します。

    3. アプリの名前(既定では「無題 (n)」)をクリックして、わかりやすい名前(例: Notepad++ (MSI))に変更します。

    2. 概要タブの入力

    [概要] タブで、以下の項目を入力します。

    • 説明: 例)Notepad++ 8.9.7 (x64 MSI) をサイレント インストールします。
    • 公開元: Notepad++ Team
    • バージョン: 配布するインストーラーのバージョン(例: 8.9.7)
    • オンデマンド インストール: [デバイス] ページから任意のデバイスに手動インストールできるようにする場合は有効にします(POC では既定のオフのままで問題ありません)。

    3. パッケージ タブでのアクション設定

    [パッケージ] タブを開くと、既定で [ファイルのダウンロード] → [実行] の 2 アクションがテンプレートとして用意されています。それぞれのアクション ノードをクリックし、右側のパネルで内容を設定します。

    [ファイルのダウンロード] アクション:

    項目 設定値の例
    ダウンロード元の URL https://github.com/notepad-plus-plus/notepad-plus-plus/releases/download/v8.9.7/npp.8.9.7.Installer.x64.msi
    SHA256 ハッシュ値 GitHub リリース ページに記載のダイジェスト値(任意: ピア ダウンロード利用のために設定)

    既定の [実行] アクションは削除し、代わりにパッケージ アクション一覧から [MSI の実行] を追加します。MSI 専用アクションは、汎用の [実行] アクションで msiexec.exe とコマンドライン引数を手組みするよりも設定項目が少なく、サイレント インストールのオプションもあらかじめ用意されているため簡単に構成できます。

    [MSI の実行] アクション(MSI をサイレント インストール):

    項目 設定値の例
    ファイル ダウンロードした npp.8.9.7.Installer.x64.msi を選択
    操作 インストール
    表示オプション 非表示(サイレント)

    一般に、アプリの配布は最低 1 つの [ダウンロード] アクションと 1 つの [実行] 系アクション(実行 または MSI の実行)から構成される必要があります。設定内容にエラーがなければ画面右上の [保存] が有効になるので、変更コメントを入力して保存します。

    4. 配布タブでのターゲット設定

    [配布] タブを開くと、既定で削除できない 2 つの配布が表示されます。

    • システム - 除外するデバイス(優先順位 1): このアプリを配布しないデバイスを指定する配布。既定は空。
    • システム - オンデマンド インストール: [デバイス] ページからのオンデマンド インストールに使われる配布。

    新しい配布を追加するには:

    1. [配布を追加] をクリックします。
    2. 配布名(例: POC - client-2nchvny3)を入力します。
    3. [ターゲット] タブの [デバイスを追加] から対象デバイス(例: client-2nchvny3)を検索して選択し、[追加] します。
    4. [スケジュール] タブで配布のタイミングを確認します。既定は [エージェント チェックインを開始](次回のエージェント チェックイン時にインストール)。即時に反映したい場合は [選択した日時の後にエージェント チェックインを開始] を選択するか、後述の [今すぐ実行] を使用します。
    5. [保存] をクリックします。

    5. 配布のリアルタイム実行(任意)

    既定のスケジュールでは、対象デバイスの次回チェックインまでインストールが行われません。POC で即座に動作確認したい場合は、配布一覧の行のオプション メニュー(⋮)から次のいずれかを選択します。

    • すべてのデバイスで今すぐ実行: この配布の対象となるすべてのデバイスでインストールを試行します。
    • 準拠していないデバイスで今すぐ実行: 現在準拠していないデバイスのみを対象にインストールを試行します。

    配布後の確認(配布ステータス)

    配布を実行したら、[アプリの配布] > [配布ステータス] で結果を確認します。

    1. [アプリの配布] > [配布ステータス] を開きます。
    2. 検索ボックスにデバイス名(例: client-2nchvny3)を入力して絞り込みます。

    3. 対象アプリ(例: Notepad++ (MSI))の行で、以下の列を確認します。

      列 内容
      デバイス 対象デバイス名
      アプリケーション 配布したアプリ名
      状態 準拠(インストール済み)/ 保留中(次回チェックイン待ちまたは実行中)/ 非準拠(失敗)
      結果 直近のアクション結果の要約
      配布 どの配布(ターゲット設定)によりインストール対象になったか
      前回のステータス更新 / 開始日 ステータスが更新された日時 / 配布が開始された日時

    4. 行の右端のオプション メニュー(⋮)から、配布ログ概要や、そのデバイスに割り当てられたアプリの一覧(JSON 形式)を確認できます。また、失敗時にはここから [再試行](準拠済みデバイスなら [同期])を実行できます。

    状態が保留中のまま変わらない場合

    「今すぐ実行」を行った直後は 保留中 のまま数分〜数十分表示されることがあります。エージェントのチェックイン間隔(既定 4 時間おき)とターゲット設定サービスの解決間隔(既定 6 時間おき)の兼ね合いのため、時間をおいて [更新] ボタンで再確認してください。

    トラブルシューティングの入口

    症状 最初に確認すること
    配布ステータスに「デバイス エージェント ポリシーでアプリの配布が有効になっていません」と表示される エージェント ポリシーの [機能] で [アプリの配布] が有効になっているか、対象デバイスが最新ポリシーを取得しているか
    状態が「保留中」から進まない エージェントのチェックイン間隔(既定4時間)。急ぎの場合は配布の「今すぐ実行」を利用
    状態が「非準拠」になる [MSI の実行] アクションの操作・表示オプションの設定。ダウンロード URL や SHA256 ハッシュ値の誤り
    ピア ダウンロードが利用されない ダウンロード アクションで SHA256 ハッシュ値が未設定の場合、ピア ダウンロードは利用されずソースから直接ダウンロードされる仕様。ピア ダウンロードを利用する場合はハッシュ値を設定
